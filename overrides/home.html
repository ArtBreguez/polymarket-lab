Prediction markets, without lookahead.

pmlab is a plugin-based ML framework for Polymarket. Write four methods for a market family; pmlab does the rest: edge and cost arithmetic, walk-forward backtests, a hard GO / NO_GO gate before anything is promoted, paper trading, and settlement that waits until the truth is final.

It will not look ahead, or ship a loser.

Enforced in code and checked by the test suite, not left to convention. Each claim below links to the page that shows how.

  1. No lookahead.

    rolling_origin_eval trains only on rows from before the day it predicts. build_panel refuses a price seen at or after the decision it informs, and check_no_leakage raises when a feature gives the outcome away.

  2. A failed gate cannot ship.

    ChampionManifest.publish raises unless the gate says GO, and that is not configurable. On the sample the gate reads every city, one of them loses money, and publishing is refused. Scope the champion to the cities that pass and it publishes, with that scope recorded in champion.json.

  3. Reproducible.

    Every backtest records its seeds, library versions, resolved config and a fingerprint of the data. pmlab reproduce re-runs it and verifies that the metrics come back.

    reproduce → {{ s.reproduce.status }}  data match: {{ 'yes' if s.reproduce.data_match else 'no' }}  metrics compared: {{ s.reproduce.metrics_compared }}
    Reproducibility

  4. Frozen API.

    From 1.0 pmlab follows semantic versioning. What is public is compared with a checked-in snapshot on every change, and nothing public is removed before 2.0 without a deprecation warning that names the replacement.

    {{ s.api.names }} public names in {{ s.api.modules }} modules · {{ s.api.commands }} CLI commands · tests/api/public_api.json
    What is public

  5. Five rules, in code.

    A champion is never published with a NO_GO gate. Canonical training data is never overwritten without an explicit flag. Workspaces are never mixed: live forward evidence and training data stay apart. The champion's segment gate is always read from champion.json, the record made at promotion. A trade is never settled before MarketPlugin.is_truth_final says the truth is final.
